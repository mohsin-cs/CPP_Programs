# C++ Programs

C++ programs from my BS (CS) coursework, covering programming fundamentals, data structures and algorithms.

## Contents

| Folder | What's inside |
|---|---|
| `Data_Structures/` | Binary Search Tree, AVL Tree, Red-Black Tree |
| `Sorting_techniques/` | Bubble, Merge, Quick, Heap, Count, Bucket and Radix sort |
| `Assignments/` | Calculator, number guessing, Fibonacci series, coins problem, matrix multiplication, word counting in a file, task scheduler |
| `Semester_Projects/` | Airplane management system and student registration system, both using OOP and file handling |

## Running a program

```bash
g++ Sorting_techniques/Merge_Sort.cpp -o merge_sort
./merge_sort
```

Each `.cpp` file is self-contained and compiles with any C++11 or later compiler.
